# 🏠 Casas Catandica - Barué

Site de aluguer e venda de casas em Catandica, Barué - Moçambique.

### Tecnologias
- HTML, CSS, JavaScript
- Supabase (banco de dados)
- Adsterra (monetização)

### Funcionalidades
- Lista de casas em tempo real
- Botão WhatsApp direto
- Anúncios visíveis

Feito por um programador de Moçambique.
